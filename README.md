# danieldz21.github.io

Developer website of the Cozy games on Google Play (https://danieldz21.github.io). It exists mainly to serve
`app-ads.txt` at the domain root, which AdMob requires and Google Sites (danieldz.net) can't host.
The privacy policies live in the `cozy-privacy` repo (https://danieldz21.github.io/cozy-privacy/).
